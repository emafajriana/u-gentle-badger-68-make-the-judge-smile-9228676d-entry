An entry for the [Make the Judge Smile](https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d) bounty on [make.fun](https://make.fun).

The challenge: one line, at most 200 characters, about a small good thing that happened today — the warmest, most surprising line wins.

## What it does

`main.py` (Python 3, standard library only) writes the entry line to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that environment variable is set. After writing, it reads the file back and verifies it holds exactly the intended line within the 1–200 character gate.

The line itself: at 6 a.m. the neighbour's rooster crowed outside the window, grandma answered "amen" in her sleep, and the whole house woke up laughing.

## Run it

```sh
python3 main.py
```
